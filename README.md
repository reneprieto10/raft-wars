# Raft Wars

Juego de artillería por turnos en HTML5. Un solo archivo, sin dependencias.

**Jugar:** https://reneprieto10.github.io/raft-wars/

Arrastra para apuntar y suelta para disparar. El daño sube con la potencia del
impacto y con lo cerca que pegues de la cabeza. Cada golpe paga, y con la plata
compras armas mejores en la tienda entre niveles.
